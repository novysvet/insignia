This packet contains twelve deliberately difficult research assignments. They
are intended to produce mathematics, algorithms, counterexamples, and small
CPU reference implementations that can change an inference-engine decision.
They are not requests to run the private model or to invent benchmark numbers.
Every file is self-contained and can be handed to an independent agent.

The packet is broader than NVFP4. It covers autoregressive distribution shift,
recurrent-state stability, representation observability, coded storage,
occupancy optimization, sequential experimentation, hyper-connection
stability, selective prediction, causal residual coding, speculative
checkpointing, causal information limits, and joint adaptive compute.

## Universal submission standard

A serious answer must separate assumptions from facts, state at least one
theorem or impossibility result, include adversarial instances, provide a
deterministic CPU implementation, expose all free parameters, and finish with
an engine decision plus a kill criterion. A negative result is valuable when
it rules out an expensive CUDA or data-collection sidequest.
