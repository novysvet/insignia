# Joint adaptive compute synthetic outputs

These files are generated by the CPU-only Problem 12 artifact. They are
synthetic and do not contain RTX 4070 or GLM-5.3-Flash measurements.

- `exact-policy.json`: exact finite occupation-measure solution.
- `model-summary.json`: 252-state / 8,190-action-start finite model schema.
- `fixed-sweep.csv`: exact stationary evaluation of all 32 fixed tuples.
- `voi-table.csv`: one-step exact-metric value by posterior difficulty.
- `counterexamples.json`: nonseparability and unstable-combination cases.
- `summary.csv`: pooled ratio-of-sums simulation results from 12 replications.
- `replicate-summary.csv`: every per-seed simulation row and raw denominator.
- `action-frequency.csv`: pooled action-start frequencies.
- `aggregate.json`: machine-readable results, confidence notes, safety price,
  and kill criteria.
- `aggregate.txt`: compact human-readable pooled table.
- `solve.txt`: exact LP console report and policy support.
- `validation.txt`: focused test output and exact-solver validation.

Recreate an exact solution and one simulation with:

```bash
cd tools
python test_joint_adaptive_compute.py
python joint_adaptive_compute.py --solve-demo
python evaluate_joint_adaptive_compute.py \
  --rounds 500 --seed 12012 \
  --out-dir ../scratch/joint-adaptive-compute-run
```

Pool independent `run-*` directories with
`tools/aggregate_joint_adaptive_compute.py`.
